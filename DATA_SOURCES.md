# Data sources and scope

The committed `src/data/pokemon/pokemon.json` snapshot is derived from `@pkmn/dex` 0.10.11, upstream https://github.com/pkmn/ps, which unifies Pokémon Showdown data layers. The package is locked in package-lock.json and used only by the generation script, not shipped as a runtime dependency in the browser.

Run `npm run data:generate` to reproduce the snapshot. Review the generated diff, then run all checks. The snapshot contains 1,025 base species, English names, types, generation and six base stats from the Generation 9 Dex. Regional/alternate forms, Mega evolutions, move sets, items, abilities and competitive legality are outside this phase.

The initial format is an explicitly **casual National Dex planning pool**, not an official or Showdown competitive format. Earlier species marked Past in the Gen 9 game are deliberately retained. Do not use this pool to assert Scarlet/Violet availability, VGC legality, tier bans or current metagame performance.

The upstream code/data package is MIT-licensed. See THIRD_PARTY_NOTICES.md for the license notice. Pokémon names and intellectual property remain with their owners; this notice does not grant rights to official artwork. Sprite binaries are produced by the build (see below) and are not committed to the repository.

The generated type-chart.json stores all 324 Generation 9 standard matchups from the same pinned Dex source. Rows are attackers and columns are defenders; dual types multiply. Stellar and battle mechanics are excluded.

## Pokémon sprites
`npm run sprites:generate` (also run automatically by `predev` and `prebuild`) downloads the 475×475 official-artwork PNG for every species in `src/data/pokemon/pokemon.json` from PokeAPI/sprites at commit a3a1432e688ea028f12c51371d5253037cb9f17b via jsDelivr, then writes two WebP sizes into the ignored `public/sprites/official/{160,320}/` directory: 160px for picker, partner and evolution cards (42–100px on screen) and 320px for team, recommendation and guide-hero art (105–180px). Raw PNGs are cached in the ignored `.sprite-cache/`, so reruns only resize; `--force` regenerates every size. The step is incremental and fails when any species is missing, and `npm run check:build` re-verifies the two directories inside `dist/`.

The shared PokemonSprite component, the guide directory and the builder all read those same-origin files, keyed by National Pokédex number, with fixed image dimensions and lazy loading outside selected team cards. Small cards also advertise both sizes through `srcset`, so a 2× or 3× display fetches the 320px file instead of upscaling 160px. A failed request falls back to the Pokédex number while the name and type badges stay visible. Nothing contacts the sprite CDN at runtime, so sprite display no longer depends on third-party CDN availability, and scoring and selection remain local.

Before this change the browser requested the 475×475 PNG for each picker result: one 60-result page transferred 8.63 MB and needed 60 cross-origin requests that each paid their own TLS round trip (measured 0.9–2.8 s time to first byte per image). The same 60 requests now transfer about 0.4 MB of ~7 KB WebP files from the site origin, roughly 95 percent less.

## Official type symbols
The 18 SVG files in public/type-icons are original assets downloaded from the official Japanese Pokémon Pokédex, https://zukan.pokemon.co.jp/img/icon_type_1.svg through icon_type_18.svg. The mapping was verified against https://zukan.pokemon.co.jp/zukan-api/api/masters/ and the site's CSS/search implementation on 2026-10-05. Order: Normal, Fire, Water, Grass, Electric, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel, Fairy. SVG bytes are preserved; no competitor or fan redraw is used. Pokémon assets remain the property of their respective owners; attribution is not a license grant or endorsement.

## Score typeface
The team score number is set in Archivo Black, a heavy grotesque used as the digits of an action-game damage number. Only the ten digits are shipped: `public/fonts/archivo-black-digits.woff2` is Google Fonts' own U+0030–U+0039 subset (3,620 bytes), committed to the repository on 2026-10-08 and served from the site origin, so no runtime request goes to a third-party font host. The `@font-face` is declared in `src/styles/global.css` under the CSS family name `Score Digits` and applies to `.score-value` only; `/ 100`, ratings, prose and every other glyph keep the body font. Because the subset contains no letters, any non-digit character in that element falls back automatically. The colouring is a CSS treatment, not a font feature: a cream-to-gold `linear-gradient` fill clipped to the text (`background-clip: text`) inside a `#4a2c12` `-webkit-text-stroke` painted *behind* the fill via `paint-order: stroke fill`. The stroke width is set in `em` so it scales with the 28px/22px breakpoints. The face and this treatment were taken from a reference site the user pointed to (genshindamagecalculator.com), whose damage numbers were read through `getComputedStyle` rather than guessed at; only the styling recipe was copied, no asset or file from that site is used.
